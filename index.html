できること

🎁

ギフト・コメント・いいねで発動

ギフト（画像つき一覧から選択）、コイン数の範囲、コメント（全文/一部/先頭一致）、いいね数（全体/個人）、フォロー、シェア、入室——豊富なトリガーを組み合わせてルールを作成。

⚔️

Minecraft も、それ以外のゲームも

Minecraft サーバーへはコマンドを直接送信（RCON）。その他のゲームにはキー入力送信や HTTP リクエストで対応。ゲームごとにプリセットを保存してタブで切り替えられます。

🔊

コメント読み上げ

Windows 標準ボイスと VOICEVOX（ずんだもん等）の両対応。読み上げ対象をサブスクライバー限定などに絞ることも可能。

📺

OBS オーバーレイ

URL を OBS のブラウザソースに貼るだけで、ギフト・フォロー・シェアの通知が配信画面にアニメーション表示。高額ギフトは特別演出。

🎯

細かい発動条件

対象ユーザーの指定、サブスク/フォロワー/ギフト経験者などの属性フィルタ、クールダウン、再フォロー除外、1人あたりの回数制限まで設定できます。

🖥️

ブラウザで完結する管理画面

接続・ルール編集・テスト発火・送信ログをリアルタイムのダッシュボードで。ドライランで安全に動作確認してから本番へ。

動作環境

Windows 10/11。TikTok Live の配信者アカウント（ギフト連携には LIVE 権限が必要）。 Minecraft 連携には RCON が有効な Java 版サーバー（Paper 等）。 読み上げ・オーバーレイはネットワーク接続のみで動作します。

よくある質問

TikTok 公式のツールですか？

いいえ。個人開発の非公式ツールです。TikTok Live への接続はコミュニティで広く使われている方式を採用していますが、TikTok 側の仕様変更により一時的に接続できなくなる可能性があります。その際はアップデートで対応します。

解約したらどうなりますか？

ライセンスキーが失効し、無料版の機能範囲に戻ります。作成したルールやプリセットの設定データは消えません。

ライセンスは何台まで使えますか？

ご自身の配信用 PC を想定して複数台のアクティベーションに対応しています（台数上限は購入ページに記載）。

返金はできますか？

決済プラットフォーム（Lemon Squeezy）のポリシーに準じます。まず無料版で動作確認いただくことをおすすめします。

本ソフトウェアは現状有姿で提供され、TikTok・Minecraft 等の外部サービスの仕様変更による機能停止について開発者は責任を負いません。 ライセンスキーの共有・再配布・リバースエンジニアリングは禁止です。配信での利用はご自身のアカウント・コンテンツポリシーの範囲で行ってください。

本ソフトウェアは利用者の PC 上でのみ動作し、配信データを開発者のサーバーへ送信しません。 ライセンス認証のためキー情報のみが決済プラットフォーム（Lemon Squeezy）に送信されます。
